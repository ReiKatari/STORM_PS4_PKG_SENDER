# STORM Token Optimizer (Rust Token Killer - RTK)

## Назначение
Максимизирует полезный сигнал в контекстном окне LLM за счёт интеллектуальной фильтрации, дедупликации и сжатия вывода терминальных команд без потери критически важных данных и кодов возврата.

## Основные команды и шаблоны использования:
1. **Операции Git**:
   - `rtk git status` — компактный статус, сгруппированный по состоянию файлов.
   - `rtk git diff` — сжатый diff без лишних заголовков и раздутого контекста.
   - `rtk git log -n 10` — хэш, автор и тема коммита в одну строку.
   - `rtk git add .` / `rtk git commit -m "..."` — компактное подтверждение без шума.
2. **Запуск тестов (-90% мусора)**:
   - `rtk cargo test` — вывод только упавших тестов, свернутые счетчики пройденных.
   - `rtk pytest` / `rtk npm test` / `rtk vitest` / `rtk jest` — фильтрация трейсов и сводка ошибок.
   - `rtk test <cmd>` — универсальный адаптер для любых тестов.
3. **Поиск и анализ файлов**:
   - `rtk grep <query>` — группировка совпадений по файлам, отсечение сверхдлинных строк.
   - `rtk find "<pattern>"` — компактный список найденных файлов.
   - `rtk read <file>` — умное чтение файла с фокусом на сигнатуры и структуру.
   - `rtk ls <dir>` — компактное дерево с подсчетом файлов.
4. **Сборка, линтинг и диагностика**:
   - `rtk lint` — группировка ошибок по правилам и файлам.
   - `rtk tsc` — группировка ошибок компиляции TypeScript.
   - `rtk err <cmd>` — фильтрация ошибок и предупреждений для произвольной команды.
5. **Диагностика экономии токенов**:
   - `rtk gain` / `rtk gain --history` — детальный отчёт о сэкономленных токенах.
   - `rtk proxy <cmd>` — запуск команды без сжатия при необходимости сырого вывода.
