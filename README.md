<h1 align="center">STORM PS4 PKG SENDER</h1>

## **О проекте**
**STORM PS4 PKG SENDER** — высокопроизводительный десктопный инструмент для скоростной передачи, пакетной установки, мониторинга и автоматизации развёртывания пакетов PKG на игровых консолях PlayStation 4 (GoldHEN Remote Package Installer, DirectPackageInstaller и PackegeFlowService). Сервер обеспечивает прямую потоковую передачу данных на предельной скорости гигабитного сетевого интерфейса (100–115 МБ/с) с аппаратной поддержкой HTTP/1.1 Range Requests для докачки, контроля целостности сессий и мгновенного возобновления установки.

## **Происхождение и архитектура**
Оригинальная высокопроизводительная разработка в составе экосистемы утилит **STORM SOFT**. Архитектура объединяет классический протокол Remote Package Installer от **flat_z** и **SiSTRo**, скоростной бинарный пейлоад DirectPackageInstaller (порт 9090), интеграцию со службой консольного компаньона PackegeFlowService от **demagoc3-cpu** (порт 12801), а также встроенный автоматический торрент-пайплайн qBittorrent и Torznab. Программа построена на базе модульного асинхронного стека Python 3.12 и графического фреймворка PyQt6 с собственной системой быстрого бинарного парсинга заголовков Sony Orbis PKG и расширенным двухпанельным FTP-проводником.

## **Технологический стек**
- **Язык программирования**: Python 3.12 (C-Extensions, ctypes, wintypes)
- **Графический интерфейс**: PyQt6, динамическая система 47 тем оформления (включая 8 фирменных 3D-стилей STORM SOFT), мультиязычный движок (6 языков с автоопределением языка системы)
- **Сетевое ядро**: Многопоточный HTTP/1.1 Range Streaming Server (сокетные буферы 256 КБ, поддержка частичной загрузки, тайм-аут сторож 20 секунд против зависаний)
- **Интеграция с PS4**: Remote Package Installer API (v1 и v2), протокол GoldHEN REST, инъекция пейлоада DirectPackageInstaller (порт 9090), REST API PackegeFlowService (порт 12801), SSDP сетевое обнаружение консоли
- **Автоматизация загрузок**: qBittorrent Web UI API (v2, поддержка схем авторизации 4.x и 5.x QBT_SID), Torznab XML клиент (Jackett и Prowlarr), механизм трансляции путей NAS/SMB
- **Обработка данных**: Бинарный seek-парсер PlayGo/Orbis PKG и SFO-контейнеров, автоматический генератор GP4-проектов и модуль бэкпортов для ранних версий системного ПО

## **Ключевые возможности**
- **Гигабитная скорость передачи**: Прямая отдача PKG-файлов без промежуточного копирования на пределе пропускной способности сети (100–115 МБ/с).
- **Выбор транспорта установки**: Поддержка трёх независимых сетевых транспортов:
  1. *Remote Package Installer (GoldHEN)* — стандартный протокол через JSON REST API.
  2. *DirectPackageInstaller (Пейлоад порт 9090)* — скоростной транспорт с обратным сокетным соединением, выводом названия игры и иконки `icon0.png` в системных уведомлениях консоли.
  3. *PackegeFlowService (порт 12801)* — фоновая служба консоли с детальным контролем установки.
- **Интеллектуальный сторож Range Requests (20-секундный watchdog)**: Автоматическое отслеживание реальной передачи байтов, исключающее ложные статусы завершения при сбоях фонового установщика консоли.
- **Автоматизация торрентов и Torznab**:
  - Встроенный поиск игр, обновлений и дополнений через Torznab-индексаторы (Jackett, Prowlarr) прямо в интерфейсе программы.
  - Интеграция с qBittorrent Web UI с автоматическим отслеживанием завершённых загрузок, распознаванием структуры папок и трансляцией сетевых путей сетевых хранилищ (NAS).
  - Автоматическая постановка скачанных PKG в очередь установки на PS4 без участия пользователя.
- **Консольный компаньон (Console Companion)**:
  - Мониторинг системной информации консоли: версия системного ПО, модель PlayStation 4, статус GoldHEN.
  - Детальный расклад хранилища: занятое и свободное пространство внутреннего накопителя HDD и внешних USB-дисков.
  - Интерактивный каталог установленных игр с возможностью раскрытия списка дополнений (DLC) и патчей.
  - Точечное и безопасное удаление компонентов без потери сохранений пользователя.
- **Прокачанный FTP-проводник**:
  - Панель быстрого перехода по ключевым каталогам консоли (`/user/app/`, `/user/patch/`, `/user/addcont/`, `/user/home/`, `/data/`, `/mnt/usb0/`, `/mnt/usb1/`, `/mnt/ext0/`).
  - Навигационные элементы управления (назад, вперёд, переход на уровень выше) и ручной ввод путей.
  - Контекстное меню локальных файлов с командой мгновенной отправки в очередь PKG Sender.
- **Мгновенный парсинг PKG**: Сверхбыстрое чтение TitleID, категории (Game, Patch, DLC, Theme), региона и метаданных без загрузки всего файла в оперативную память.
- **Очередь и пакетная отправка**: Drag and Drop добавление файлов и каталогов, автоматическая сортировка по порядку (Игра → Патч → DLC).
- **Модуль бэкпортов (Backport Tool)**: Автоматическая адаптация игр и обновлений под более низкие версии системного ПО консоли (полная матрица из 40 версий от 5.05 до новейшей 14.00, включая 6.72, 7.55, 9.00, 11.00, 12.00, 13.00, 13.52 и 14.00).
- **Контроль единственного экземпляра**: Защита от конфликтов портов и блокировки сокетов через глобальный системный Mutex (`Global\STORM_PS4_PKG_SENDER_SingleInstanceMutex`).
- **100% мультиязычность**: Полная поддержка 6 языков (Русский, Английский, Немецкий, Французский, Китайский, Японский) с автоматическим выбором языка операционной системы при первом запуске.

## **Поддерживаемые платформы**
- **Операционные системы ПК**: Windows 11, Windows 10 (x64)
- **Целевые консоли**: Sony PlayStation 4 (Fat, Slim, Pro) с прошивками от 5.05 до 14.00 под управлением GoldHEN, Remote Package Installer или PackegeFlowService

## **Установка и запуск**
1. Скачайте инсталлятор `STORM_PS4_PKG_SENDER_1.4.0_Setup.exe` или портативный архив `STORM_PS4_PKG_SENDER_1.4.0.zip` из раздела **Releases**.
2. Запустите приложение. При первом запуске язык интерфейса будет автоматически согласован с языком операционной системы.
3. Введите IP-адрес консоли или воспользуйтесь кнопкой автоматического поиска в локальной сети.
4. Перетащите PKG-файлы в окно программы или настройте автоустановку через торрент-клиент qBittorrent.
